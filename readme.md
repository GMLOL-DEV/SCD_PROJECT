# Peshawar BRT Route Finder

## Project Overview

The **Peshawar BRT Route Finder** is a console-based Python application designed to help passengers using the Bus Rapid Transit (BRT) service in Peshawar, Pakistan, identify suitable buses for traveling between two stations.

Passengers may find it difficult to determine which bus to take because different services follow different routes and stopping patterns. Some buses stop at every station along their routes, while express services skip certain stations.

This project aims to simplify the process by allowing users to enter their starting and destination stations and view the buses that serve both locations.

### Main Objectives

- Identify direct buses between two BRT stations.
- Maintain organized information about stations and bus routes.
- Handle different stopping patterns, including express services.
- Support travel in both directions where the service operates.
- Display relevant journey stops and route information through a simple console interface.
- Provide a foundation for future journey planning involving bus transfers.
